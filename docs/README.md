# Mental Health Tracker Website

This directory contains the website files for the Mental Health Tracker iOS app, designed to be hosted on GitHub Pages.

## Setup for GitHub Pages

1. Create a new repository on GitHub (or use an existing one)
2. Push the contents of the `docs` folder to the repository
3. Go to your repository settings → Pages
4. Set the source to "Deploy from a branch"
5. Select the branch (usually `main` or `master`) and folder `/docs`
6. Your site will be available at `https://[username].github.io/[repository-name]/`

## Files

- `index.html` - Main landing page
- `privacy.html` - Privacy policy page
- `.nojekyll` - Prevents Jekyll processing (needed for GitHub Pages)

## Customization

- Replace the placeholder app screenshot in `index.html` with actual app screenshots
- Update the App Store badge link when the app is published
- Customize colors, fonts, and content as needed
- Add actual app screenshots to showcase the app

## Notes

- The design is minimal and monospaced, matching the app's aesthetic
- All styling is inline for simplicity
- The site is responsive and works on mobile devices
